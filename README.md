# Towa AI - Exclusive Customer Support Chatbot Widget

'Towa' (towastore.shop) ই-কমার্স প্ল্যাটফর্মের জন্য নিবেদিত, প্রিমিয়াম এবং ফুললি ফাংশনাল এআই কাস্টমার সাপোর্ট চ্যাটবট উইজেট।

---

## 💎 বৈশিষ্ট্য ও আর্কিটেকচার

1. **একক উদ্দেশ্য (Single Purpose Architecture):**
   - শুধুমাত্র কাস্টমার সাপোর্ট চ্যাটবট উইজেট ও এর ব্যাকএন্ড API রুট (`/api/chat`)।
   - এডমিন প্যানেল বা অন্য কোনো অপ্রয়োজনীয় মডিউল নেই।

2. **UI/UX ও ফ্লোটিং উইজেট (Bottom-Right Floating Widget):**
   - স্ক্রিনের একদম নিচে ডান কোণায় (Bottom-Right Corner) মিনিমালিস্ট ফ্লোটিং চ্যাট বাটন।
   - শতভাগ নির্ভরযোগ্য React State Toggle: ক্লিকে ইনস্ট্যান্ট স্মুথ অ্যানিমেশনের সাথে চ্যাট উইন্ডো ওপেন হয় এবং ক্রস (`X`) এ ক্লিক করলে বন্ধ হয়।

3. **কালার থিম (Minimalist Black & White):**
   - কোনো সবুজ বা অতিরিক্ত কালার নেই।
   - প্রিমিয়াম ব্ল্যাক হেডার ও একসেন্ট, ক্লিন হোয়াইট মেসেজ কন্টেইনার এবং প্রফেশনাল কন্ট্রাস্ট।

4. **জেমিনি এআই ও নলেজ বেজ (Gemini Integration):**
   - গুগল জেমিনির লেটেস্ট মডেল `gemini-3.8-flash` ও স্মার্ট অটো-ফলব্যাক।
   - নলেজ বেজ রুলস:
     * **ব্র্যান্ড:** Towa (towastore.shop)
     * **পেমেন্ট:** ১০০% ক্যাশ অন ডেলিভারি (COD) সমগ্র বাংলাদেশে। কোনো অনলাইন পেমেন্ট গেটওয়ে নেই।
     * **অর্ডার ও লজিস্টিকস:** এসএমএস গেটওয়ের মাধ্যমে স্বয়ংক্রিয় অর্ডার কনফার্মেশন ও ট্র্যাকিং আপডেট।
     * **সাপোর্ট ইমেইল:** `support@towastore.shop` / `info@twice-gem.com`
     * **ক্যাটালগ:** ১৮৬+ কিউরেটেড প্রোডাক্ট (গ্রোসারি, স্ন্যাকস, বিস্কুট, টয়লেট্রিজ)।
     * **আচরণবিধি:** অত্যন্ত মার্জিত, প্রমিত বাংলায় সরাসরি উত্তর; কোনো অপ্রয়োজনীয় ইমোজি বা রোবটিক ফিলার ছাড়া।
